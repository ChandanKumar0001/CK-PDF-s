# 📄 CK-PDF's — Online PDF Utility Web Application

🚀 **Live Link: https://ck-pdf-s.onrender.com/

*(Note: Hosted on Render's free tier; initial load may take 30–50 seconds if the server is in sleep mode.)*

A fast, user-friendly, and full-stack web application for managing and processing PDF documents online. Built with **Node.js**, **Express**, and **EJS**, and deployed live on **Render**.

---

## ✨ Features

* **PDF Processing & Manipulation:** Easily handle, generate, or modify PDF files directly from your browser.
* **Clean & Responsive UI:** Simple, intuitive interface designed for smooth navigation across devices.
* **Fast Backend Architecture:** Powered by Express.js with modular routing and server-side rendering.
* **Zero Setup Required for Users:** Works directly online without installing any external software.

---

## 🛠️ Tech Stack

* **Backend:** Node.js, Express.js
* **Templating Engine:** EJS (Embedded JavaScript)
* **Frontend:** HTML5, CSS3, JavaScript
* **PDF & Graphics Processing:** Canvas / PDF Libraries
* **Deployment:** Render (CI/CD integrated with GitHub)

## 💻 Run Locally on Your Machine

Follow these steps to set up and run the project locally:

### 1. Clone the repository
```bash
git clone https://github.com/ChandanKumar0001/CK-PDF-s.git
cd CK-PDF-s
```

### 2. Install dependencies
*(Recommended Node.js version: **v20.x**)*
```bash
npm install
```

### 3. Start the server
```bash
node index.js
```

### 4. Open in browser
Visit **`http://localhost:8080`** in your web browser.
